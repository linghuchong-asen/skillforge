# 测试用例模板（specs/test-cases.md）

```
# 测试用例：<项目名称>

- 日期：yyyy-mm-dd
- 状态：待确认 / 已确认
- 前置：architecture.md 已确认

## 用例清单

| 编号 | 类型 | 关联 FR | 优先级 | 前置条件 | 步骤 | 预期结果 | 状态 | 测试文件 |
|---|---|---|---|---|---|---|---|---|
| TC-1 | 单元 | FR-1 | P0 | <…> | <…> | <…> | 未实现 | — |
| TC-2 | 集成 | FR-2 | P0 | <…> | <…> | <…> | 未实现 | — |
| TC-3 | E2E | FR-3 | P1 | <…> | <…> | <…> | 未实现 | — |

## 说明
- 状态取值：未实现 / 已实现 / 通过 / 失败 / 已移除（原因）/ 人工。

- 无法自动化的用例标注「人工」并说明原因。

## 变更记录
<与 PRD/架构的结构变更同步记录>

```
# 部署运维：<项目名称>

- 日期：yyyy-mm-dd
- 状态：待确认 / 已确认
- 前置：architecture.md 已确认

## 1. 环境与发布配置
- 环境划分：<开发 / 测试 / 预发 / 生产，各自的用途与地址>
- 配置管理：<环境变量、配置文件位置；密钥用占位符并说明注入方式，不写真值>
- 基础设施依赖：<数据库、缓存、对象存储、CDN 等>

## 2. 部署方案
- 构建产物：<如何构建、产物是什么>
- 部署步骤：<可执行的命令/流程清单>
- 回滚方案：<如何回退到上一版本、数据兼容性说明>

## 3. 灰度发版
- 灰度策略：<按用户白名单 / 流量比例 / 特性开关（feature flag）/ 多环境预览，说明选择理由>

- 观察指标与观察时长：<每批次观察的错误率、延迟、业务指标及最少观察时间>

- 回退条件：<触发什么指标立即回退、回退操作步骤>
- 灰度验收：<全量前的最终确认项>

## 4. 监控与告警

- 关键指标：<需要监控的指标清单>
- 告警规则与通知渠道：<阈值、通知方式>

## 5. 应急预案
- 故障场景 F1：<现象 + 处置步骤>
- 值班/联系人：<如适用>
